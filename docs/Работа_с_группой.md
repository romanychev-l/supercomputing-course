# Совместная работа с группой

На занятии дайте короткую задачу на 15–30 минут: найти воспроизводимый дефект, проверить 3–5 слайдов или собрать одну практику. Студент фиксирует результат в issue и продолжает дома в PR. Для крупных переносов разделяйте страницы заранее, чтобы работы не пересекались.

## Организация GitHub

1. Пригласите участников. В приватном репозитории проверьте, доступен ли им Fork; при необходимости выдайте доступ к рабочим веткам. Весь комплект, включая преподавательские эталоны, будет им виден.
2. Используйте метки `latex`, `theory`, `practice`, `documentation`, `good first issue`, `help wanted`. Студент пишет в issue, какие страницы берёт; преподаватель назначает ответственного при наличии возможности.
3. Для большой задачи откройте отдельные issues на непересекающиеся части. Не закрывайте общий issue после переноса нескольких страниц.
4. В настройках main включите правила проверки PR и успешного CI, если они доступны для выбранного плана GitHub. Слияние оставьте преподавателю. Автоматические правила в этом репозитории ещё не настроены.
5. Раз в неделю просмотрите открытые PR и дайте короткое ревью. Полезны также обоснованные замечания в чужих PR и воспроизводимые отчёты о дефектах.

## Как видеть активных участников

GitHub Issues и PR сохраняют авторов, обсуждения, проверки и принятые изменения. В поиске репозитория используйте `is:pr author:LOGIN`, `is:pr is:merged author:LOGIN` или `is:issue author:LOGIN`. Вклад reviewer можно смотреть по содержательным ревью. В Insights → Contributors видны коммиты, но один график не отражает всей работы.

Для оценки смотрите на корректность, самостоятельное объяснение, воспроизводимость проверки, качество ревью и доведение работы до принятия. Число коммитов, строк и мелких PR легко увеличить искусственно; оно не должно определять оценку. Не публикуйте таблицы с личными оценками студентов в репозитории.

## Задания всему классу

| Формат | Результат |
| --- | --- |
| Проверка формулы | Определения, допущения, размерности, крайние случаи, ссылка на первичный источник и точечный PR |
| Перенос 3–5 слайдов | Редактируемый LaTeX, исходная нумерация, проверка изображений страниц, журнал расхождений |
| Запуск практики на другой ОС | Реальные команды, версии, контрольный ответ; улучшение инструкции |
| Проверка условия задачи | Неоднозначность, маленький контрпример и согласованное исправление |
| Воспроизводимый эксперимент | Малый набор сырых измерений, окружение, график и объяснение ограничения |
| Ревью чужого PR | Конкретная содержательная проверка с аргументами, а не формальное одобрение |

Использование агента разрешено, но объяснение и проверку защищает студент. Для преобразования слайдов назначьте другого участника проверяющим: он сверяет результат с оригинальными страницами и не полагается на отчёт автора.
