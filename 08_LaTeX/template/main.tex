\begin{frame}{Пример набора: ускорение}
  Для доли последовательной работы $0\leq\alpha\leq1$:
  \[
    S_N=\frac{1}{\alpha+(1-\alpha)/N}.
  \]
  \begin{itemize}
    \item Предположение: фиксированный объём работы.
    \item Накладные расходы в этой модели не учитываются.
    \item При $N=1$ получаем $S_1=1$.
  \end{itemize}
\end{frame}
