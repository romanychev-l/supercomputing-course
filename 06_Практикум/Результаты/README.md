# Локальный пример измерения

30.10.2026, Apple M1, 8 CPU, macOS 26.7.1, Apple Clang 21 и LLVM OpenMP 21.1.8. Интеграл для π, N=10^7, -O2, static schedule, динамическое изменение числа потоков отключено. По одному прогреву и пять измеряемых запусков каждой конфигурации.

Файлы local_pi.csv и local_pi.summary.json содержат сырые результаты и итог. Графики local_pi.png/svg построены из этого JSON. Медианы: последовательная версия около 16,0 ms; OpenMP 1 поток — 18,4 ms, 2 — 9,34 ms, 4 — 4,90 ms. Ускорение на четырёх потоках около 3,26 относительно последовательной программы и 3,76 относительно OpenMP на одном потоке. Разные базы показаны отдельно.

Это небольшой учебный локальный опыт на текущей машине. Фаза короткая, режим частот и фоновая нагрузка не контролировались как в строгом аппаратном исследовании; результаты не переносятся на кластер. Во время включены вычисление и редукция, а создание начальной команды для узнавания её размера выполнено заранее. Это объясняет, почему нельзя использовать числа как универсальную стоимость первого запуска OpenMP.

Параметр repetitions в отчёте — число самостоятельных запусков с измерением ядра, не повторение kernel внутри одного процесса. Если требуется более устойчивое исследование, выбирайте более длинную измерительную фазу и документируйте дополнительную организацию повторов. Не меняйте методику только ради красивого ускорения.
