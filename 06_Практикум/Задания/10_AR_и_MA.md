# Практика 10. Зависимая рекурсия и независимое окно

Время: одна пара. Нужны массивы, граф зависимостей и редукция/scan.

## Общий вход

ε[i]=(i mod 5)−2, 0≤i<N. Вход детерминирован и одинаков при любом числе потоков. Это позволяет изучать алгоритм независимо от качества RNG. Для малых проверок N=1,4,17,32.

## MA(2)

y[i]=0,5ε[i]+0,3ε[i−1]+0,2ε[i−2], отсутствующие элементы с отрицательным индексом считаются нулём. При готовом ε каждый выход независим. Реализуйте parallel for; в MPI каждый блок дополнительно получает два предыдущих входных значения либо вычисляет их по глобальному индексу. Для N=4 ответ `[-1.0, -1.1, -0.7, 0.3]` (десятичные точки).

## AR(1)

y[−1]=0, y[i]=0,75y[i−1]+ε[i]. Простой parallel for по i неверен. Представьте каждый шаг как f_i(y)=a_i y+b_i. Композиция (a,b) после (c,d) даёт (ac,ad+b). Операция ассоциативна математически, поэтому префиксный scan даёт все состояния. Поэтапный эталон applied.py показывает чтение старого массива и запись нового на каждом уровне. Параллельная реализация ставит границу между уровнями; внутристадийные элементы можно распределять.

## Проверка

Сравнить со строго последовательной рекурсией с допуском. Для первых четырёх AR-значений ожидается [-2.0,-2.5,-1.875,-0.40625]. Не требуйте побитового совпадения scan при любом размере: порядок округлений может отличаться. Укажите работу O(N log N) учебного scan и глубину O(log N); более сложный work-efficient вариант — расширение.

Сдать формулы, код, контрольные массивы и анализ зависимостей. Python-эталон проверяет математику, **не является измерением ускорения параллельной реализации**. Студент пишет собственный OpenMP/MPI-вариант, если выбран программный уровень задания.
