# Практика 11. FFT: стадии и независимые бабочки

Время: одна пара. Обязательный вариант — понимание и проверка малой реализации; параллельный вариант задаётся по подготовке группы.

## Условие

DFT: X[k]=Σ_j x[j] exp(−2πijk/N), k=0…N−1. Для radix-2 FFT взять N=2^m. Объяснить битовую перестановку, log2(N) стадий и независимые бабочки внутри одной стадии. Между стадиями нужны готовые результаты предыдущей. Эталон applied.py реализует FFT и независимый прямой DFT; он предназначен для малых N≤256.

## Проверка

1. Импульс x=[1,0,0,0] → X=[1,1,1,1].
2. Константа x=[1,1,1,1] → X=[4,0,0,0] с небольшими округлениями.
3. Для x=[1,2,3,4] ожидается [10,−2+2i,−2,−2−2i].
4. Сравнить все элементы FFT и DFT для N=1,2,8,32 по максимальной комплексной ошибке.
5. При обратном преобразовании нормировка 1/N применяется ровно один раз. Прямой FFT в этом задании не нормирован.

## Параллельное расширение

Распределить независимые блоки/бабочки стадии между потоками, сохранив барьер до следующей стадии. Для MPI описать, какие пары выходят за пределы локального блока и требуют обменов; не просто запустить полную FFT на каждом ранге и назвать это распределённой FFT. Многомерная FFT часто использует глобальные перераспределения/транспонирования; это обсуждение по документации FFTW, не обязательная самостоятельная промышленная библиотека за одну пару.

Сдать схему N=8, код, тесты и оценку O(N log N) против O(N²). Сравнение быстродействия с прямым DFT не является чистым сильным масштабированием одного алгоритма. Для основного курса достаточно освоить стадии и корректную OpenMP-версию; распределённая FFT — проект для подготовленных студентов.
