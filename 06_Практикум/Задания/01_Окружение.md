# Практика 1. Подготовить воспроизводимый запуск

Время: одна пара. До начала нужны основы терминала Linux и C/C++. Результат: студент самостоятельно собирает последовательную программу, понимает вход/выход и сохраняет сведения об окружении.

## Условие

Создайте рабочую папку без исходников преподавательских решений. Напишите C-программу, которая для N>0 вычисляет сумму a[i]=(i mod 97)−48, 0≤i<N. Размер передаётся аргументом. Для неверного размера программа завершает работу с ненулевым кодом и понятным сообщением. Никакого интерактивного ввода внутри измерений.

Сохраните сведения о системе: ОС, модель/число доступных CPU, память, компилятор и его версия, наличие OpenMP, MPI и планировщика. Не включайте пароли, приватные ключи и токены. Сборка должна включать предупреждения; пример для Linux: `cc -O2 -std=c11 -Wall -Wextra program.c -o program`.

## Проверка

N=1 → −48; N=3 → −141; N=97 → 0; N=101 → −186. Для общего случая полный период из 97 элементов даёт ноль. Остаток r=N mod 97 даёт r(r−1)/2−48r. Это независимый контроль, не второй запуск той же ошибки. Проверьте N=0, −1 и нечисловую строку.

## Сдать

Исходник, точную команду сборки, README с запуском и четыре результата. На защите объяснить границы цикла и переполнение выбранного типа. Для основной серии ограничить N≤10^7; тип суммы должен вмещать промежуточные значения. Преподавательский эталон — kernels.c, режим sum.

Ритм пары: 15 минут окружение, 35 программа, 20 проверка, 20 обсуждение. Если среда не готова, это выявляется сейчас и не расходует занятие по MPI.
