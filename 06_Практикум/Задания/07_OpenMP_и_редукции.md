# Практика 7. OpenMP: независимые итерации и общий результат

Время: одна пара. Обязательный минимум — сумма и скалярное произведение; интеграл дополнительный, затем используется в измерениях.

## Условие

Реализуйте последовательную и OpenMP-версии. Для суммы a[i]=(i mod 97)−48. Для произведения a[i]=i+1, b[i]=(i mod 7)−3, ответ Σa[i]b[i]. Нужен один и тот же результат при 1,2,4 потоках и N=1,3,101, затем на большом N. Запишите атрибуты каждой переменной. Сумму объединяйте reduction, входы доступны только для чтения.

Для интеграла вычислите π≈(1/N)Σ4/(1+((i+1/2)/N)²). Сравните с последовательным методом той же квадратуры и отдельно с математическим π. Положительный N≤10^7, неверный ввод отклоняется. Измерение без printf внутри цикла.

## Проверка

Сумма для N=101 равна −186. Скалярное произведение для N=3 равно −10: −3−4−3. Для N=1 интеграл даёт 3,2 — это не ошибка MPI/OpenMP, а грубая квадратура. Используйте абсолютный+относительный допуск, например |x−ref|≤10^−10·max(1,|ref|) на тестовых входах. Утверждение о независимости итераций необходимо даже при прошедших тестах.
