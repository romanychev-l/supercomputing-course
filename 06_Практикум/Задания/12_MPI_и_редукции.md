# Практика 12. Распределить сумму и интеграл

Время: одна пара. Базовые функции: Init/Finalize, rank/size, Reduce. Сначала p=1, затем 2,3,4.

## Условие

Повторить сумму a[i]=(i mod 97)−48 и интеграл для π из задания 7 в MPI. Каждому процессу назначить полуинтервал [start,start+count), покрывающий свою часть. Размеры не обязаны быть равны. Допускается детерминированно вычислять локальный вход по глобальному индексу, поэтому передавать весь массив не требуется. Если вход хранится у root, реализовать Scatterv как расширение.

Для N элементов и p процессов: q=N/p, r=N mod p; count(k)=q+[k<r], start(k)=kq+min(k,r). Пустой блок даёт 0 в SUM. Программа обязана работать при p>N. Таймер каждого процесса измеряет локальную длительность, затем берётся максимум. Сбор времени сам не включён в измеряемую фазу, если протокол так объявлен.

## Проверка

N=1,17,101 при p=1,2,3,4. Для N=101 сумма −186. Для интеграла сравнение с последовательной квадратурой при том же N с допуском 10^−10·max(1,|ref|). Проверить N=0 и неверную строку: все процессы согласованно завершаются, никто не остаётся ждать коллектив.

## Сдать

Код, команды mpicc/mpiexec, результаты, пять повторов на большом N и вывод о масштабировании. Отличить локальные процессы от нескольких узлов; локальный результат не подтверждает скорость сети кластера. Эталон mpi_sum_pi.c и verify.py дают проверяемый контракт. Нельзя вызывать Reduce только у root. Массивы с одинаковым именем в разных процессах не являются одним общим объектом.
