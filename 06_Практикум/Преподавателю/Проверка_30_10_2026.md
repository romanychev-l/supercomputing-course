# Журнал фактических проверок — 30.10.2026

Этот журнал описывает исполнение программ. [Проверка содержания курса](../../03_Обзор/Фактчекинг_30_10_2026.md) ведётся отдельно: 158 запусков не означают проверки 158 фактов или всей теории.

## Окружение

Проверки выполнены локально на Mac Apple M1 (8 физических/логических CPU, arm64), macOS 26.7.1, Apple Clang 21.0.0. OpenMP: библиотека LLVM 21.1.8 из conda-forge, совместимая с компилятором; MPI: MPICH 5.0.2 (локальные процессы, ch4:ofi). Зависимости размещались во временной папке, системные компиляторы и пакеты не менялись. Проверочные бинарные файлы требуют этой среды; переносимый результат — исходники и команды пересборки.

Сначала обнаружена несовместимость старой libomp 15 с Apple Clang 21 (отсутствующий символ __kmpc_dispatch_deinit). Проверка продолжена с LLVM OpenMP 21.1.8. Это была проблема совместимости инструментов; исходный код не заменял parallel фиктивным последовательным исполнением. MPI требовал разрешённых локальных соединений launcher, после чего тесты выполнены нормально.

**158 проверочных запусков** в двух основных наборах: 149+9. Первые 48 — подмножество, повторно к этой сумме не прибавляются. Число запусков не означает формального доказательства алгоритмов; логические свойства отдельно разобраны в конспектах и методике.

Оба проверяющих сценария завершились `status=passed`. У DCMT контрольные числа взяты из реально собранного и запущенного авторского new_example2.c для ID 0/1, поиска с seed 4172, начальных seed 1234/4567. Таким образом проверяется не только совпадение двух запусков нашего загрузчика, но и совпадение с авторским примером.

## Что проверяли по существу

Сумма сверяется с формулой полного периода/остатка, dot — с отдельным скалярным расчётом, matvec — с аналитической формулой, maxmin/tri — с независимыми Python-циклами. Интеграл сравнивается с квадратурой того же порядка. Halo сравнивается по всем элементам с отдельным последовательным stencil. Набор layout проверяет столбец, size/extent, суммы split, соседей кольца и звезды. Есть p>N в сумме и явное отклонение этого случая у halo.

FFT сверяется с прямым DFT; AR-scan — с последовательной рекурсией; MA — с ручным малым вектором. Checkpoint восстанавливается в новых процессах с точек 0,1,17,99,100 и сравнивается с непрерывным запуском. Испорченный файл отвергается. Для MT проверена воспроизводимость при изменении числа потоков и dynamic-расписания; статистическое качество этим не утверждается.

## Ограничения

Slurm-шаблоны проверены локально по синтаксису, **реальная очередь и межузловой запуск не проверены**. Нет данных об учебном кластере, его модулях, partition/account и launcher. Попытка проверить доступный DEV по SSH завершилась отсутствием ответа; сервер не использовался для вычислений и не менялся. Этот сервер также не объявляется учебным кластером без подтверждения.

Нет полученного исходного проекта generate_zeta и BLAS-сравнения автора. Нет готовой промышленной распределённой FFT, всех студенческих вариантов atomic/critical/lock, двух обходов памяти и гибридного эталона: они даны как самостоятельные упражнения с явно описанной проверкой. Python-прикладные проверки подтверждают математические эталоны, а не реализованную студентом параллельность. Sanitizer, статистические пакеты качества RNG и MPI-анализатор гонок не запускались; такого результата не заявляем.

На другом компьютере выполнить make и оба сценария заново. После получения кластера дополнить журнал одним малым Slurm-заданием и несколькими конфигурациями на двух узлах. Не переносить показатели локального Mac на будущую аудиторию.

После уточнения о доступе добавлены папка «Локально», два минимальных исходника, локальный вариант практики 4 и правила сдачи. Оба новых примера собраны и запущены на этом же Mac: OpenMP сообщил threads=2; MPI сообщил ранги 0/1 из двух процессов на одном и том же компьютере. Удалённые узлы и SSH для них не использовались. Это две дополнительные проверки стартовых примеров, не повтор всего набора из 158 запусков.

Учебный CSV очереди специально составлен для упражнения и не является журналом настоящего Slurm. Инструкции установки для Windows/WSL и Linux проверены по официальным источникам, но на этих платформах нами не исполнялись. Отсутствие такого платформенного теста не скрывается.
