# Ответы к локальному варианту практики 4

Файл «Локально/учебная_очередь.csv» — **намеренно составленные учебные данные**, не выгрузка Slurm и не свидетельство выполненных заданий. Столбцы упрощены для объяснения; это не точный формат всех версий sacct. Его разрешено выдавать студентам вместе с условием.

- 1001: штатное завершение; выделено 4 CPU, приложение использовало 4 потока, время меньше лимита, контрольный ответ обозначен правильным.
- 1002: не найден исполняемый файл. Проверить путь, рабочий каталог и наличие результата сборки. Увеличение памяти/CPU не исправляет путь.
- 1003: достигнут лимит времени. Сначала проверить размер задачи и алгоритм, затем обоснованно изменить запрос либо применить checkpoint. Не считать время ожидания в очереди временем ядра.
- 1004: превышен лимит памяти. Оценить массивы на процесс, уменьшить размер/репликацию либо запросить достаточную память по правилам центра. Из кода завершения одного без detail не следует универсальная точная причина.
- 1005: успешный ответ при 8 потоках на 2 выделенных CPU. Ресурс переподписан; четыре аппаратно параллельные работы на каждый CPU отсюда не возникают. Исправить согласование OMP_NUM_THREADS и запроса. Быстрое/правильное завершение не доказывает разумную конфигурацию.
- 1006: пока ожидает ресурс, нет времени выполнения и кода завершения. Пустая ячейка elapsed не означает успешно завершённую задачу за ноль секунд.

Последняя часть сдачи — реальный локальный запуск с собственным журналом/выводом и версиями. Его нельзя смешивать с учебным CSV. Проверка shell-синтаксиса batch-файла допустима, но ни она, ни локальный запуск через bash не считаются запуском Slurm.

Оценка локального варианта из 10: 2 за обоснованный ресурсный запрос, 4 за диагнозы шести строк, 2 за реальный локальный запуск, 2 за различение локального результата и учебных данных. Требование реального job ID для этого варианта отсутствует.
