# Шаблоны для учебного кластера

Отправлять из корня практикума после сборки: `sbatch Slurm/openmp.sbatch` либо `sbatch Slurm/mpi.sbatch`. В первом случае программа должна показать 4 потока, во втором — 4 процесса. Запрошен один узел, поэтому это ещё не межузловой эксперимент.

До отправки уточнить partition, account, модули и допустимый MPI-launcher. В шаблонах намеренно нет выдуманных названий центра. Для MPI прямой srun допустим только при настроенной интеграции; иначе команду заменяют по инструкции центра. Библиотека сборки и launcher должны быть согласованы.

Проверить очередь: `squeue -u "$USER"`. Сохранить ID из ответа sbatch и журнал. История при доступном учёте: `sacct -j JOB_ID --format=JobID,State,Elapsed,AllocCPUS,ExitCode`. JOB_ID заменить реальным номером. Синтаксическая проверка `bash -n` не подтверждает работоспособность Slurm или доступность раздела.

Для нескольких узлов нужны доступный ресурс, согласованное число задач на узел и новый реально проверенный запуск. Не менять nodes на большое число всей группой без лимитов. Копирование этих шаблонов не означает, что такие ресурсы уже выделены.
