# Практикум: 15 занятий и проверяемые примеры

Подготовлено 30.10.2026. [План всего курса](../03_Обзор/План_15_лекций_и_15_практик.md) связывает каждую пару с теорией. Задания рассчитаны на 90 минут в аудитории с продолжением самостоятельной работы. Пререквизиты — терминал Linux и базовый C/C++; для части эталонов используется Python 3.

**Доступ к кластеру для обязательных программных заданий не требуется.** Основной запасной маршрут — [все 15 практик на обычном компьютере](Локально/README.md): Linux, Windows/WSL или macOS, начальные примеры и отдельная сдача практики 4 без Slurm. Работа парами на подготовленных компьютерах аудитории допустима. Настоящий кластер — расширение при наличии доступа; локальная сдача не требует job ID и не штрафуется за отсутствие нескольких узлов.

## Сборка эталонов преподавателя

Из этой папки на Linux с установленными C/C++-компиляторами, OpenMP, MPI и make:

```sh
make all
python3 Инструменты/verify.py
python3 Инструменты/verify_dcmt.py
```

Можно собирать отдельно: `make serial`, `make openmp`, `make mpi`, `make dcmt`. Если MPI отсутствует, `python3 Инструменты/verify.py --serial-only` явно проверяет только последовательную часть и Python-эталоны, а не весь курс. DCMT поставляется с исходниками и лицензией в «Внешние_библиотеки»; цель dcmt собирает её автоматически.

Если установлено несколько MPI-реализаций, выбирайте wrapper и launcher одной реализации явно. Например, для пакетов MPICH в Ubuntu/Debian из этой папки:

```sh
MPIEXEC=/usr/bin/mpiexec.mpich make check MPICC=/usr/bin/mpicc.mpich
```

После смены MPI пересоберите MPI-бинарники (`make -B mpi MPICC=/usr/bin/mpicc.mpich`). Смешение wrapper и launcher может приводить к запуску отдельных однопроцессных MPI-миров вместо одного общего мира; проверка числа процессов должна обнаруживать такую ошибку, а не пропускаться. Именно эту пару инструментов явно использует CI.

На Mac команда gcc может означать Apple Clang. Нужны совместимая OpenMP-библиотека и одна MPI-реализация; пути задаются через CC/CXX/MPICC/OMPFLAGS в make. Пример при уже установленных Homebrew libomp/mpich:

```sh
make all CC=clang CXX=clang++ MPICC=/opt/homebrew/bin/mpicc \
  OMPFLAGS='-Xclang -fopenmp -isystem /opt/homebrew/opt/libomp/include -L/opt/homebrew/opt/libomp/lib -Wl,-rpath,/opt/homebrew/opt/libomp/lib -lomp'
```

Это пример пути Apple Silicon, не команда установки. Если библиотека отсутствует, сначала готовят окружение с администратором/по правилам компьютера. Для наших проверок зависимости были временно размещены отдельно; локальные бинарные сборки не являются переносимым комплектом на другой компьютер. Из исходников нужно пересобрать.

## Контракт проверяемых бинарных файлов

Последняя строка stdout — JSON; ненулевой код означает ошибку. Поля seconds в секундах и value проверяются по смыслу задачи. Входные данные заданы формулами в условиях, поэтому отдельных больших файлов не требуется.

| Файл в build | Аргументы | Выход |
| --- | --- | --- |
| kernels_seq / kernels_omp | sum, dot, pi, matvec, tri либо maxmin; затем N | mode,n,threads,value,seconds |
| mt_seq / mt_omp | N | n,threads,checksum как строка |
| mpi_sum_pi | sum либо pi; N | mode,n,processes,value,seconds |
| mpi_halo | N STEPS, 1≤p≤N | n,steps,processes,seconds,values |
| mpi_layout | нет | processes,ok,column,type_size,extent |
| dcmt_seq / dcmt_omp | create FILE либо run FILE N | created/streams либо n_per_stream/checksums |

Kernels допускает 1≤N≤10^7; матричные режимы дополнительно N≤4096. Halo: N≤10^6, steps≤10^4; для вывода большого вектора используйте малые проверочные размеры, а измерительный вариант адаптируйте без полного вывода. Проверка содержимого выполняется вне измеряемого ядра.

Для студенческих C/C++-решений с тем же контрактом: `python3 Инструменты/verify.py --bin-dir /абсолютная/папка/сборки`. Launcher задаётся `--mpiexec` или MPIEXEC, например для выбранной реализации. Python-секция этого сценария проверяет поставленные математические эталоны, а не студенческие AR/FFT автоматически.

## Измерения

```sh
python3 Инструменты/benchmark.py --mode pi --n 10000000 --threads 1 2 4 --repeats 5
```

Будут сохранены сырые CSV и JSON с медианой, разбросом и двумя базами ускорения. Число потоков выбирается в пределах разрешённого ресурса. Полученные на этом Mac данные лежат в «Результаты/local_pi.*» и являются **локальной демонстрацией**, не прогнозом учебного кластера. Подробности интервала измерения есть в задании 2 и исходнике.

Для графика можно выполнить `python3 Инструменты/plot_timings.py Результаты/local_pi.summary.json` в среде с matplotlib. В отличие от проверяющих сценариев, этот необязательный инструмент требует внешнюю библиотеку. Готовые PNG/SVG локального опыта сохранены рядом с CSV.
